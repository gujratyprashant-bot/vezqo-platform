# VEZQO Platform

Fresh rebuild using Next.js App Router and TypeScript. No Lovable runtime or legacy application code is included.

## Local development

1. Install Node.js 20.9+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` after services are configured.
4. Run `npm run dev`.

## Planned integrations

- A new Supabase project for authentication and database
- Server-side Cashfree integration
- Vercel hosting

Never commit production credentials. Configure secrets in Vercel Environment Variables.
